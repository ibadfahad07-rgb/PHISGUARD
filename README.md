# PhishGuard

PhishGuard is a Flutter-based mobile app I built as a cybersecurity project to help users identify suspicious or potentially malicious links.

## What it does

- Scans URLs for phishing risk
- Gives users a simple risk result
- Uses a clean mobile interface designed for quick checks
- Built as a practical cybersecurity learning project

## Built with

- Flutter
- Dart
- Android

## Project status

The app is complete and has been built for Android. I plan to keep improving it and publish a public release in the future.

## Why I built it

I created PhishGuard to improve my skills in mobile development and cybersecurity by building something practical that solves a real problem.
